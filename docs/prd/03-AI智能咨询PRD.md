# AI 智能咨询 PRD

## 1. 产品定位

“江南 AI 助手”作为原江南 e 平台的嵌入式服务入口，为用户提供找标的、看懂标的、查政策、查流程和咨询当前项目等能力。助手不替代原有搜索、客服和正式公告，而是降低信息获取门槛并把用户引导回原业务流程。

## 2. 使用场景

| 场景 | 页面上下文 | 典型问题 | 预期结果 |
|---|---|---|---|
| 平台接待 | 首页/公共页面 | 怎么报名？保证金何时退？ | 基于已发布规则回答并给出入口 |
| 智能找标的 | 首页/列表页 | 找海宁 20 万以内商业用房 | 提取条件，返回可筛选的推荐卡片 |
| 政策查询 | 政策法规页 | 农村产权竞买人需要什么条件？ | 引用有效政策、显示适用范围和日期 |
| 标的咨询 | 标的详情页 | 这个标的适合做什么？ | 自动带入当前标的，结合挂牌信息回答 |
| 成本与材料 | 标的详情页 | 三年成本多少？报名要什么？ | 结构化计算，列出已知、未知和依据 |
| 异常兜底 | 任意页面 | 无法确认或涉及个人业务状态 | 明确无法判断并引导登录或人工服务 |

## 3. 页面入口与形态

### 3.1 首页入口

- 在不破坏原平台布局的前提下，放置醒目的“江南 AI 助手”入口；
- 首次访问显示欢迎气泡，用户关闭后 7 天内不重复自动弹出；
- 点击后打开侧边对话面板，桌面端建议宽度 420—480px；
- 移动端改为全屏会话页或底部抽屉。

### 3.2 标的详情页入口

- 使用同一助手品牌和会话组件；
- 打开后自动识别当前项目 ID、标的 ID 和公开状态；
- 首条欢迎语概括标的名称、位置、面积、期限和起始价；
- 快捷问题根据标的类型、已知字段和交易阶段动态生成。

### 3.3 嵌入方式

正式方案由原平台技术条件确定，优先级如下：

1. 原前端工程以组件/微前端方式接入；
2. 受控 iframe＋安全消息通信；
3. 独立页面跳转作为降级方案。

无论采用何种方式，前端不得直接保存模型密钥；登录态通过短期令牌或服务端会话传递。

## 4. 会话生命周期

1. 用户首次打开时创建会话 ID；
2. 匿名会话使用浏览器临时标识，不与真实身份关联；
3. 登录用户可在授权范围内保存最近会话，默认保留 30 天，期限待业主确认；
4. 页面切换时保留会话，但更新页面上下文；
5. 切换到另一标的时，助手提示“已切换当前标的”，避免串用上一标的数据；
6. 超过 30 分钟无操作可标记会话闲置，再次提问时重新校验上下文和业务状态；
7. 用户可新建会话、清空当前会话和删除本人历史会话。

## 6. 自然语言找标的

### 6.1 可识别条件

- 区域：市、县区、街道/乡镇；
- 业务板块和标的类型；
- 用途/经营场景；
- 起始总价、年租金、单价区间；
- 建筑面积、土地面积；
- 租赁期限；
- 报名状态、报名截止时间；
- 交易方式；
- 是否有停车、交通、产业等偏好；
- 排序偏好：最新、价格、面积、匹配度、热度。

### 6.2 处理流程

1. 解析用户意图和槽位；
2. 将识别结果以可编辑条件标签展示；
3. 对价格单位、时间和区域歧义进行澄清；
4. 调用正式标的搜索接口，不由模型虚构结果；
5. 返回 3—5 个优先推荐，并显示“共找到 N 个”；
6. 支持继续筛选、查看更多、修改条件和进入详情。

### 6.3 推荐卡片字段

- 标的名称、类型、区域、面积；
- 起始价及计价单位；
- 报名状态和截止时间；
- 2—3 条匹配理由；
- 数据更新时间；
- 查看详情按钮。

若字段为空，显示“暂未提供”，不得补造真实值。

## 7. 回答结构

正式回答建议使用统一结构：

1. **直接结论**：先回答用户问题；
2. **关键事实**：列出与问题最相关的字段；
3. **条件和限制**：说明缺失、例外、资格或时间限制；
4. **依据来源**：展示公告、规则、项目数据、历史成交或外部数据标签；
5. **下一步操作**：查看详情、报名入口、咨询标的、转人工等。

### 7.1 来源标签

| 标签 | 含义 |
|---|---|
| 挂牌信息 | 原业务系统结构化项目/标的数据 |
| 交易公告 | 当前有效公告原文或附件 |
| 交易规则 | 已发布且适用的业务规则 |
| 政策法规 | 有效政策法规或规范文件 |
| 历史成交参考 | 经授权的历史成交样本 |
| 周边资源数据 | 经授权的地图或公共数据，显示数据日期 |
| AI 研判 | 模型基于上述依据形成的辅助判断 |

用户点击标签后打开引用抽屉，展示来源标题、适用范围、发布时间/更新时间、引用片段和原文入口。

## 8. 重点问答规则

### 8.1 时间类

- 必须从业务接口读取，不使用模型记忆；
- 显示完整年月日时分和时区；
- 已截止时明确显示“已截止”；
- 接近截止时可显示剩余时间，但以服务器时间为准；
- 接口异常时不得返回缓存中的过期时间。

### 8.2 价格与成本类

- 明确币种、含税/不含税、单价/总价和周期；
- 展示计算公式和假设；
- 对租金递增、免租期、税费、物业费等缺失项单独列出；
- 不把起始价表述为最终成交价；
- 历史参考需显示样本数、区域、时间范围和可比性限制。

### 8.3 资格和材料类

- 只引用当前项目有效公告及正式规则；
- 区分“必须”“可能需要”“暂未提供”；
- 对自然人/企业、联合体、行业资质等条件分别说明；
- 固定提示“最终以交易机构资格审查结果为准”。

### 8.4 经营适配和投资判断

- 使用“适合度参考”“AI 研判”“建议核实”等措辞；
- 不承诺客流、收益或升值；
- 至少列出一个优势和一个待核实事项；
- 区分原始事实与 AI 推断。

## 9. 多轮对话与上下文

- 支持指代消解，例如“这个项目”“三年呢”“保证金呢”；
- 会话上下文仅保留完成当前任务所需内容；
- 当前标的上下文优先于历史会话中的其他标的；
- 用户改变筛选条件时更新查询条件而非叠加错误条件；
- 对关键业务字段每次回答前重新查询或校验缓存时效；
- 当上下文存在多个候选标的时，先让用户选择，不自行猜测。

## 10. 快捷问题

### 10.1 首页

- 帮我找海宁的农村产权项目；
- 有哪些正在报名的商业用房；
- 如何参加网上竞价；
- 保证金什么时候退；
- 按区域、价格和用途筛选标的。

### 10.2 详情页

- 这个标的适合做什么；
- 周边人口和产业情况怎么样；
- 租金水平是否合理；
- 三年/五年总成本是多少；
- 报名需要哪些材料；
- 是否有优先权人；
- 有哪些重要风险和限制；
- 与类似历史标的相比如何。

快捷问题由后台配置，可按页面、标的类型、交易阶段和用户身份生效。

## 11. 异常、拒答和降级

| 场景 | 系统行为 |
|---|---|
| 业务接口超时 | 提示暂时无法获取实时信息，提供重试和人工渠道；不使用过期关键字段 |
| 知识检索无结果 | 明确“当前资料未提供”，建议查看公告或咨询交易机构 |
| 多来源冲突 | 列出冲突字段，优先正式公告并标记待人工确认 |
| 用户询问个人状态但未登录 | 引导登录，不要求在对话中输入身份证号等敏感信息 |
| 用户输入敏感信息 | 前端和服务端脱敏；提示不要发送身份证、银行卡等信息 |
| 高风险法律/投资结论 | 提供事实与来源，不作法律裁决或收益承诺 |
| 模型服务不可用 | 降级到关键词检索、常见问题和人工服务 |
| 恶意/无关内容 | 简短拒答，并提示平台可服务范围 |

## 12. 用户反馈与转人工

- 每条回答支持“有帮助/无帮助”；
- 无帮助时可选原因：答案不准确、没解决问题、依据不足、信息过期、其他；
- 支持一键转人工或提交工单，并经用户确认后附带必要会话摘要；
- 工单不得默认包含用户未授权的完整历史会话；
- 后台可查看高频未解决问题并转为知识补充任务。

## 13. 埋点与效果指标

| 事件 | 关键字段 |
|---|---|
| 助手曝光/打开/关闭 | 页面、用户类型、会话 ID、时间 |
| 提问 | 意图、页面上下文、是否登录；原文按脱敏策略保存 |
| 条件识别 | 识别槽位、用户修改项、置信度 |
| 推荐曝光/点击 | 推荐批次、标的 ID、排序位、匹配分 |
| 引用点击 | 来源类型、文档 ID、片段 ID |
| 转人工 | 原因、工单 ID、处理结果 |
| 回答评价 | 回答 ID、评价、原因 |
| 后续转化 | 收藏、咨询、报名、竞价、成交及关联窗口 |

## 14. 后台配置

- 欢迎语、快捷问题和入口展示规则；
- 意图、同义词、业务词典和区域词典；
- 回答模板、固定免责声明；
- 推荐数量、排序规则和匹配阈值；
- 知识库生效范围；
- 模型、提示词版本和降级策略；
- 敏感词、敏感字段和拒答规则；
- 转人工渠道和服务时间。

## 15. 验收标准

1. 首页、列表页和详情页均能根据配置正常嵌入助手。
2. 详情页助手能准确绑定当前项目和标的，切换标的不串数据。
3. 自然语言找标的至少正确解析区域、类型、价格、用途、面积和状态条件。
4. 推荐结果全部来自正式搜索接口，点击可进入对应详情。
5. 报名时间、竞价时间、保证金、资格条件等回答均带来源和更新时间。
6. 无资料、冲突、超时和模型不可用时按定义降级，不生成虚假内容。
7. 用户反馈、转人工、推荐点击和后续报名链路可追踪。
8. 未登录用户无法通过对话获取非公开项目或个人业务状态。
9. 会话日志中的身份证、手机号、银行卡号等按策略脱敏。
10. 键盘操作、焦点、读屏标签和移动端基本可用。
