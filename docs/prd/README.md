## 文档目的

本套文档将已通过业主认可的 AI Demo 转化为可研发、可测试、可验收的产品需求。范围包含：

- 内部数据驾驶舱；
- AI 运营管理后台；
- 嵌入原“江南 e”业务平台的 AI 智能咨询；
- 标的详情页的 AI 资产解析；
- 智能撮合、知识库、风险辅助、数据治理、权限审计等支撑能力。

Demo 用于表达产品形态，PRD 用于定义正式系统。除明确标注“沿用 Demo”的视觉和交互外，正式系统不得直接使用 Demo 的模拟数据、固定回复或前端硬编码规则。

## 需求优先级

- **P0**：首期上线不可缺失；缺失会造成业务不可用、数据不可追溯或合规风险。
- **P1**：首期建议具备；允许在明确替代方案下延后。
- **P2**：增强能力；可进入后续迭代。

## 统一产品原则

1. AI 是原业务平台的增量能力，不替代原有报名、资格审查、缴纳保证金、竞价和成交确认流程。
2. AI 回答和分析必须展示依据来源、更新时间和适用边界；无法确认时应明确回答“暂未提供”或引导人工服务。
3. 资产、项目、标的、主体、公告、附件、报名、竞价、成交、风险事件均使用原业务系统主键关联，不另造无法映射的业务编号。
4. 所有 AI 生成内容均保留输入、模型版本、提示词版本、知识版本、输出、人工操作和发布时间，满足审计追溯。
5. 驾驶舱指标必须由统一指标服务提供，不允许各页面自行拼接不同口径。
6. 敏感数据按最小必要原则调用和展示；个人手机号、身份证号、账号等不得发送至无授权的模型或日志系统。
7. AI 风险提示不等于违规认定，AI 资产研判不构成投资建议或收益承诺。
