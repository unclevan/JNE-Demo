# 江南 e 要素交易平台 AI 能力建设产品总纲

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 江南 e 要素交易平台 AI 能力中心 |
| 文档版本 | V1.0 草案 |
| 产品形态 | 原平台嵌入式 AI 能力＋独立内部管理后台＋数据驾驶舱 |
| 目标用户 | 竞买人、产权人、交易机构业务人员、运营人员、管理人员、风控合规人员、系统管理员 |
| 原型依据 | 已获认可的江南 e AI Demo |

## 2. 建设背景

现有要素交易平台已承载资产挂牌、报名、资格审查、竞价及成交等核心交易流程，但用户仍面临三类问题：

1. **找不到**：标的数量多、字段专业、筛选条件复杂，潜在竞买人难以快速找到适配资产。
2. **看不懂**：公告、附件、资格、价格和时限分散，用户理解成本高，业务人员重复答疑量大。
3. **管不清**：管理侧缺少对资产供给、主体触达、交易转化、溢价成效和风险线索的统一观察与闭环工具。

本项目以 AI 智能咨询、AI 资产解析、智能撮合和数据驾驶舱为抓手，形成从资产进入平台到成交复盘的智能化链路。

## 3. 产品目标

### 3.1 业务目标

| 目标 | 产品手段 | 建议衡量指标 |
|---|---|---|
| 提升资产触达 | 自然语言找标的、智能推荐、主体匹配、触达任务 | 推荐触达人数、点击率、咨询率、有效报名率 |
| 提升交易竞争充分度 | 适配主体扩充、精准召回、报名转化跟踪 | 平均竞买人数、有效竞价轮次、单项目报名人数 |
| 辅助提升溢价 | 按类型和区域分析竞买人数与溢价变化 | 综合溢价率、分类溢价率、同比/环比、基准期差值 |
| 降低用户理解成本 | 公告解析、情境问答、成本测算、材料清单 | 自助解决率、转人工率、回答有用率、重复咨询下降率 |
| 提高运营效率 | AI 解析复核、撮合任务、风险闭环、自动报告 | 人工处理时长、解析通过率、任务完成率、风险闭环率 |
| 提高管理透明度 | 六页驾驶舱、指标钻取、口径说明、导出 | 数据及时率、指标一致率、报表使用率 |

### 3.2 非目标

首期不包含以下内容：

- 不替代原平台的报名、资格审查、保证金支付、竞价、合同签订及成交确认；
- 不由 AI 自动认定用户资格、违规行为或法律责任；
- 不向用户承诺资产收益、成交概率或投资回报；
- 不在未经授权的情况下自动向外部主体发送短信、电话、微信或邮件；
- 不直接改写原业务系统主数据，所有 AI 提取结果需经过规则校验或人工确认后方可回写。

## 4. 产品范围

### 4.1 面向公众和交易用户

1. 门户 AI 智能咨询入口；
2. 自然语言检索与筛选标的；
3. 推荐标的卡片及详情跳转；
4. 报名、竞价、保证金、政策与流程问答；
5. 标的详情页情境化咨询；
6. AI 资产解析及报告查看/导出；
7. 问题反馈、转人工、回答评价。

### 4.2 面向内部人员

1. 数据驾驶舱；
2. 运营工作台；
3. 资产解析任务与人工复核；
4. 智能撮合与触达任务；
5. AI 会话与咨询运营；
6. 知识库与规则库管理；
7. 风险线索与处置闭环；
8. AI 报告管理；
9. 模型、提示词、阈值和字典配置；
10. 用户、角色、权限和审计日志。

## 5. 用户角色与权限边界

| 角色 | 主要目标 | 典型权限 |
|---|---|---|
| 匿名访客 | 找标的、了解流程 | 使用公共问答、查看公开标的；不可查看个性化主体画像 |
| 注册竞买人 | 精准找标的、理解条件 | 公开问答、个性化推荐、收藏、查看本人相关材料提示 |
| 产权人/委托方 | 提升资产曝光、了解表现 | 查看本人资产分析、触达和交易表现；不可查看其他主体敏感信息 |
| 交易业务人员 | 处理解析、咨询和交易辅助 | 复核资产字段、查看项目相关会话、处理知识和风险线索 |
| 运营人员 | 配置推荐、发起触达、复盘转化 | 撮合任务、触达计划、会话分析、运营报告 |
| 风控合规人员 | 审查风险线索、形成处置闭环 | 查看完整风险依据、核验、转办、处置和关闭 |
| 管理人员 | 查看全域经营和效能 | 驾驶舱、报告、汇总数据；原则上不直接处理业务数据 |
| 知识管理员 | 维护政策、规则和问答依据 | 文档上传、切片校验、发布、下线和版本管理 |
| 系统管理员 | 维护系统和权限 | 组织、角色、菜单、参数、模型连接、审计；不默认拥有业务明文权限 |

## 7. 核心业务流程

### 7.1 资产智能运营主流程

```text
原平台产生项目/标的/公告
→ 数据同步或事件通知
→ AI 解析公告、附件和结构化字段
→ 规则校验与冲突检测
→ 业务人员复核
→ 生成资产标签、画像和分析版本
→ 匹配潜在主体
→ 运营人员审核并发起合规触达
→ 用户查看/咨询/报名/竞价
→ 回收触达与交易行为
→ 驾驶舱分析转化、竞买人数和溢价
→ 形成运营复盘与规则优化
```

### 7.2 智能问答流程

```text
用户提问
→ 识别页面上下文、用户身份和意图
→ 查询业务结构化数据
→ 检索已发布知识与公告原文
→ 规则校验和敏感信息过滤
→ 生成带依据的回答
→ 用户点击标的/继续追问/转人工/评价
→ 记录会话与效果数据
```

### 7.3 风险闭环流程

```text
规则或模型发现风险线索
→ 创建风险线索并关联项目/主体/会话
→ 风险分级与去重聚合
→ 人工核验
→ 转业务部门处理或标记误报
→ 上传处置说明和证据
→ 复核关闭
→ 驾驶舱更新闭环率与健康度
```

## 8. 核心产品对象

| 对象 | 说明 | 主数据来源 |
|---|---|---|
| 项目 | 一次产权交易项目，可包含一个或多个标的 | 原业务平台 |
| 标的 | 实际挂牌、报名和竞价的资产单元 | 原业务平台 |
| 资产 | 可长期沉淀和再次运营的资产实体 | 资产库/原业务平台 |
| 公告与附件 | 交易公告、合同、照片、评估材料等 | 原业务平台/文件系统 |
| 市场主体 | 企业、个体工商户、自然人及其他参与方 | 原业务平台/统一认证 |
| 交易行为 | 浏览、收藏、咨询、报名、审查、报价和成交 | 原业务平台/埋点平台 |
| AI 解析版本 | 某次解析的输入、字段、结论、依据和状态 | AI 能力中心 |
| 匹配关系 | 资产与主体之间的匹配分、理由和状态 | AI 能力中心 |
| 触达任务 | 经审核后执行的推荐触达及其结果 | AI 运营后台 |
| 知识条目 | 政策、公告、规则、案例及问答切片 | 知识库 |
| 风险线索/事件 | AI 或规则产生的待核验提示及处置记录 | 风险中心 |
| 指标 | 经统一口径定义的统计指标 | 指标平台/数据仓库 |

## 9. 系统边界与集成原则

### 9.1 原业务平台负责

- 用户认证、项目和标的主数据；
- 公告、报名、资格审查、保证金、竞价和成交；
- 正式交易状态与法律效力数据；
- 页面容器、路由和用户登录态。

### 9.2 AI 能力中心负责

- 问答编排、意图识别、检索增强和回答生成；
- 公告及附件解析、资产标签和分析；
- 智能匹配、推荐理由和运营辅助；
- AI 风险线索、人工复核和模型反馈；
- 模型、提示词、知识版本和调用审计。

### 9.3 数据与驾驶舱负责

- 业务数据同步、埋点采集、指标计算和快照；
- 驾驶舱查询、筛选、钻取和报告；
- 指标字典、数据质量和对账。

## 10. 成功标准

首期上线后建议至少连续观察 3 个月，并形成上线前基准期。成功标准需由业主最终确认，建议包括：

- 公共问答有依据回答率 ≥ 95%；
- 关键交易问题错误回答为 0，无法确认时必须降级；
- 资产核心字段解析准确率 ≥ 95%，字段级可复核；
- 驾驶舱核心指标与业务报表一致率 ≥ 99.5%；
- AI 推荐触达、点击、报名和竞买全链路可追踪率 ≥ 98%；
- 风险线索全流程留痕率 100%；
- 敏感信息越权展示事件为 0；
- 首屏、问答、解析任务等性能满足非功能文档要求。

## 11. 产品约束

1. 正式系统必须支持私有化或业主认可的安全部署方式。
2. 模型调用需经过统一网关，禁止前端直接携带模型密钥。
3. 公开回答只允许引用已发布且用户有权查看的资料。
4. 对报名截止、竞价时间、保证金和资格条件等高风险字段，回答必须同时显示来源与更新时间。
5. 地图、人口、企业等外部数据在未获得授权前不得当作真实生产数据。
6. 所有指标和模型分数必须支持查看定义、版本和数据更新时间。
