# 江南e要素交易平台 AI Demo 当前状态

更新时间：2026-09-08

## 项目定位

本项目是“江南e要素交易平台 AI 赋能 Demo”，用于现场演示首页智能咨询、产权标的详情和 AI 资产解析能力。项目不连接真实交易接口，不提交报名、保证金或竞价数据。

## 已完成调整

- 首页保留江南e平台蓝色政务交易平台风格，包含首页横幅、交易专区、热门标的和页脚。
- 首页右上区域增加醒目的“江南AI助手”入口，带欢迎气泡和轻微呼吸动画。
- 首页 AI 助手支持快捷问题、输入发送、AI 思考动画和本地模拟标的推荐。
- 推荐结果中包含可进入本 Demo 详情页的海宁示例标的。
- 详情页使用海宁市海昌街道老村委西原日月经编2号房仓库租赁权作为示例标的。
- 详情页包含基础字段、公告附件、交易进度、AI 情境化咨询和预设问答。
- “AI资产解析”右侧抽屉包含资产画像、投资价值研判、价格与成本分析、周边资源地图、风险与材料提示五个模块。
- 解析抽屉中的“咨询该标的”按钮已接通：点击后关闭抽屉并打开当前标的 AI 咨询面板。
- 解析报告按钮支持浏览器打印提示；地图、图层和风险信息均为本地模拟数据。
- Excel 中的联系人、手机号等敏感信息未展示；缺失字段统一显示“暂未提供”。
- 数据驾驶舱改为独立内部页面，仅通过 `?page=cockpit` 访问，不在原平台首页或导航中展示入口。
- 驾驶舱采用独立深色可视化风格，覆盖交易总览、资产供给、区域热力、交易趋势、转化链路、市场主体、AI 洞察及运行提醒。
- 驾驶舱子页已补齐资产供给、市场主体、交易效能、风险感知和 AI 洞察；页面内指标、图表、风险事件与 AI 建议均为本地模拟数据，可切换演示。
- 六个驾驶舱页面已统一为满屏尺寸和等高面板布局，补充深蓝渐变网格背景；各子页的图表、列表、地图和模拟数据会自动填满剩余视口。
- 交易总览顶部四项指标已与其他五页统一卡片样式；六个页面的顶部指标及内容面板标题均增加指标口径问号说明，支持悬停和键盘聚焦查看。
- 六个页面顶部指标卡改为左右分栏：标题及变化说明位于左侧，主数字使用等宽数字并统一靠右对齐。
- 驾驶舱栏目顺序调整为“交易总览、交易效能、资产供给、市场主体、风险感知、AI洞察”。
- 交易效能页改为以综合溢价率为中心，补充同比、环比、AI辅助前后模拟对比，以及按月份和标的类型拆分的AI触达、平均竞买人数和溢价率增效分析。
- Demo 中的数值型可视化已统一改为 ECharts：覆盖详情页资产价值雷达、价格参考、周边资源点位，以及驾驶舱总览、资产供给、市场主体、交易效能、风险感知和 AI 洞察中的折线、柱状、饼环、漏斗、散点、热力矩阵、仪表盘和主题矩形树图；鼠标移入可查看对应演示数值。
- 驾驶舱图表密度已进一步优化：交易总览的环图、漏斗、区域热力、趋势和排行铺满面板，并补齐嘉兴七个县（市、区）的演示数据；资产类型分布改为大字号信息卡，风险事件流改为双列卡片时间轴，减少大面积留白。
- 市场主体页的主体画像环图改为底部图例并居中显示；风险页放大矩阵坐标与事件卡文字、加宽合规健康仪表环，风险矩阵支持点击色块查看与格内数字一致数量的模拟风险明细；交易效能页加宽溢价率核心成效面板并加粗仪表色带。
- “交易总览”的区域交易热力分布已接入百度地图 JavaScript API 4.0 和 `BMapLib.HeatmapOverlay`：以嘉兴七个县（市、区）的本地模拟权重生成热力云团，底图隐藏道路、POI 与文字并适配驾驶舱暗色风格；鼠标移入热区可查看区域综合热度。外部地图或热力插件加载失败时自动保留 ECharts 演示图作为降级方案。
- 区域交易热度排行副标题已调整为“全市综合指数”。
- `.codex` 已补齐项目上下文、设计思想、开发交接说明和后续任务提示模板，后续修改应先阅读 `.codex/README.md`。

## 技术结构

- 前端：Vite + 原生 JavaScript + CSS + ECharts；交易总览热力底图使用百度地图 JavaScript API 4.0，无真实大模型依赖。
- 入口：`index.html`
- 页面逻辑：`src/main.js`
- 演示数据：`src/data.js`
- 样式：`src/style.css`
- 驾驶舱子页样式：`src/cockpit.css`
- 驾驶舱满屏布局修正：`src/cockpit-layout.css`
- GitHub Pages 工作流：`.github/workflows/deploy-pages.yml`
- GitHub Pages 静态资源路径配置：`vite.config.js`
- Sites 托管配置：`.openai/hosting.json`
- 内部驾驶舱直达地址：`/?page=cockpit`
- Codex 项目上下文入口：`.codex/README.md`
- 设计思想：`.codex/DEMO_DESIGN.md`
- 后续开发交接：`.codex/HANDOFF.md`
- 后续任务提示模板：`.codex/NEXT_TASK_PROMPT.md`

## 数据与演示边界

- 资产价格、周边人口、产业、历史成交、地图点位等分析数据为模拟演示数据。
- 百度地图使用浏览器端 AK，正式演示前需在百度地图开放平台将本地开发域名和 GitHub Pages 域名加入 Referer 白名单；AK 不属于服务端私密凭证，但仍应限制允许调用的域名。
- 页面分析结果只作为辅助参考，不构成收益承诺、投资建议或交易结论。
- 正式交易信息、资格要求、保证金、时间节点和合同条款以平台公告及交易机构通知为准。
