# 江南e要素交易平台 AI Demo 当前状态

更新时间：2026-10-12

## 项目定位

本项目是“江南e要素交易平台 AI 赋能 Demo”，用于现场演示首页智能咨询、产权标的详情和 AI 资产解析能力。项目不连接真实交易接口，不提交报名、保证金或竞价数据。

AI Demo 已通过业主认可，驾驶舱已开始 UI 设计。当前已进入正式产品设计阶段，正在以 Demo 为原型依据形成可供产品、UI、前后端、数据、算法、安全和测试共同使用的 PRD 文档。

## 正式产品 PRD

`docs/prd/` 已建立第一版文档集，包含：

- 产品总纲；
- 数据驾驶舱 PRD；
- AI 智能咨询 PRD；
- AI 资产解析 PRD；
- AI 运营管理后台 PRD；
- 数据、接口、权限与非功能需求；
- 研发分期与验收清单。

后续正式系统设计应以 PRD 为需求基线，以现有 Demo 为视觉和交互参考，不得将 Demo 模拟数据、固定回复或前端硬编码规则直接用于生产。

## 技术结构

- 前端：Vite + 原生 JavaScript + CSS + ECharts；后台外壳使用 Vue 3。交易总览热力底图使用百度地图 JavaScript API 4.0，无真实大模型依赖。
- 入口：`index.html`
- 页面逻辑：`src/main.js`
- 演示数据：`src/data.js`
- 样式：`src/style.css`
- 驾驶舱子页样式：`src/cockpit.css`
- 驾驶舱满屏布局修正：`src/cockpit-layout.css`
- 运营后台 Vue 挂载入口：`src/admin.js`
- 运营后台外壳、多标签与菜单状态：`src/admin/AdminApp.vue`
- 运营后台页面注册与路由元数据：`src/admin/registry.js`
- 运营后台业务页面：`src/admin/pages/*.js`
- 运营后台共享模板与弹层：`src/admin/components.js`、`src/admin/overlays.js`；图标：`src/admin/icons.js`
- 运营后台集中演示数据：`src/admin-data.js`
- 运营后台独立样式：`src/admin.css`
- GitHub Pages 工作流：`.github/workflows/deploy-pages.yml`

- 内部驾驶舱直达地址：`/?page=cockpit`
- 内部运营后台直达地址：`/?page=admin&module=workbench`

## 数据与演示边界

- 资产价格、周边人口、产业、历史成交、地图点位等分析数据为模拟演示数据。

- 页面分析结果只作为辅助参考，不构成收益承诺、投资建议或交易结论。
- 正式交易信息、资格要求、保证金、时间节点和合同条款以平台公告及交易机构通知为准。
