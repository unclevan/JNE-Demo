# 江南e AI Demo：Codex 上下文入口

后续在本项目中工作的 Codex，应在修改代码前依次完整阅读：

1. `PROJECT_CONTEXT.md`：项目目标、用户、业务价值和数据边界。
2. `DEMO_DESIGN.md`：门户 AI 与内部驾驶舱的产品设计思想。
3. `CURRENT_STATUS.md`：已经实现的页面、交互和最新调整。
4. `HANDOFF.md`：代码结构、修改原则、验证和交付要求。
5. `NEXT_TASK_PROMPT.md`：用户可以复制给新 Codex 的任务提示模板。

这些文档用于保持设计连续性。若文档与用户最新明确要求冲突，以用户最新要求为准，并在完成工作后同步更新相关文档。
